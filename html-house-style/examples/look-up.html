The request was wrong

400 Bad Request

The server could not read the request.

Check the body format and the required fields. The response body often names the part it could not parse.

Related: 422 Unprocessable Content

401 Unauthorized

No valid credentials came with the request.

Despite the name, this means not signed in. Check that a token was sent and has not expired.

Related: 403 Forbidden

403 Forbidden

The credentials were valid but do not allow this.

Check roles and permissions, not the password. Signing in again will not help.

Related: 401 Unauthorized, 404 Not Found

404 Not Found

Nothing exists at this address.

Check the path, the environment (staging or production) and whether the item was deleted. Some services answer 404 instead of 403 to hide that something exists.

Related: 403 Forbidden, 410 Gone

405 Method Not Allowed

The address exists, but not for this method.

A POST to a read-only address is the usual cause. The Allow header lists the methods that work.

Related: 404 Not Found

409 Conflict

The request clashes with the current state of the item.

Usually an edit made against an old version. Fetch the item again, reapply the change and retry.

Related: 412 Precondition Failed

410 Gone

The item existed and was removed on purpose.

Unlike 404, this is permanent. Remove the link or the stored reference.

Related: 404 Not Found

412 Precondition Failed

A condition in the request headers was not met.

Most often an If-Match version that is no longer current. Fetch again and retry.

Related: 409 Conflict

413 Content Too Large

The request body is over the size limit.

Check the limit on the proxy in front of the service as well as in the service itself.

Related: 400 Bad Request

422 Unprocessable Content

The request was readable but failed validation.

The response body usually names the field and the rule it broke.

Related: 400 Bad Request

429 Too Many Requests

You have hit a rate limit.

Wait for the time in the Retry-After header, then back off further on each retry.

Related: 503 Service Unavailable

The server failed

500 Internal Server Error

Something broke inside the service.

The client cannot fix it. Search the service logs for the request time and the request id.

Related: 502 Bad Gateway

502 Bad Gateway

A proxy got a broken reply from the service behind it.

Usually the service crashed or restarted mid-request. Check its restarts and health checks.

Related: 504 Gateway Timeout, 503 Service Unavailable

503 Service Unavailable

The service is overloaded or down for maintenance.

Retry later, honouring Retry-After if it is set. Check whether a deploy is running.

Related: 429 Too Many Requests, 502 Bad Gateway

504 Gateway Timeout

A proxy waited too long for the service behind it.

Look for slow database queries or a hung dependency. Raising the timeout hides the cause.

Related: 502 Bad Gateway

It worked

200 OK

The request worked and the body holds the result.

If the page still looks wrong, the fault is in the content, not the request.

Related: 204 No Content

201 Created

A new item was made.

Its address is in the Location header.

Related: 200 OK

204 No Content

It worked, and there is nothing to send back.

Normal after a delete or a save that returns no body.

Related: 200 OK

304 Not Modified

Your cached copy is still current, so nothing was resent.

Not an error. The browser shows its cached copy.

Related: 200 OK

It moved

301 Moved Permanently

The item has a new permanent address.

Update links. Browsers remember this redirect, so a wrong 301 lingers after it is fixed.

Related: 308 Permanent Redirect, 302 Found

302 Found

A temporary redirect; keep using the old address.

Browsers may turn a POST into a GET when following it. Use 307 to prevent that.

Related: 307 Temporary Redirect, 301 Moved Permanently

307 Temporary Redirect

A temporary redirect that keeps the method and body.

The safe choice for redirecting a form or an upload.

Related: 302 Found

308 Permanent Redirect

A permanent redirect that keeps the method and body.

Like 301, without changing a POST into a GET.

Related: 301 Moved Permanently
